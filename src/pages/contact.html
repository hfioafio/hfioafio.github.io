Pour toute question, suggestion d'outil ou signalement de dysfonctionnement :

À COMPLÉTER — adresse e-mail de contact

Nous lisons tous les messages. Les réponses peuvent prendre quelques jours : ce site est édité par une seule personne.

Signaler un outil qui ne fonctionne pas

Pour que le problème soit reproductible, précisez si possible :

  • l'adresse exacte de la page concernée ;
  • votre navigateur et votre système (par exemple « Chrome sur Windows 11 ») ;
  • le type et la taille approximative du fichier utilisé ;
  • le message d'erreur affiché, s'il y en a un.

N'envoyez jamais le fichier lui-même s'il contient des informations personnelles ou sensibles. Sa description suffit presque toujours.

Proposer un outil

Si vous butez régulièrement sur une manipulation que rien ne fait simplement, dites-le nous. Les outils de ce site naissent presque tous d'un besoin concret rencontré par quelqu'un.

Données personnelles

Pour toute demande relative à vos données, consultez d'abord la politique de confidentialité : le site ne collectant aucune donnée d'identification, la plupart des questions y trouvent leur réponse.
