Transparence technique

Pourquoi ces permissions ?

Tab Suspender agit sur les onglets du navigateur. Chrome exige donc des autorisations explicites pour les fonctions qu’il utilise. Cette page décrit leur rôle dans l’extension.

Principe : les permissions servent à suspendre, protéger et restaurer les onglets. Elles ne sont pas utilisées pour créer un profil publicitaire ni envoyer l’historique de navigation au développeur.

tabs

Permet d’identifier les onglets ouverts, leur état et leur URL, puis de les suspendre ou de les restaurer. C’est une permission centrale pour une extension de gestion d’onglets.

storage

Permet d’enregistrer les réglages, les listes de sites, les règles, l’historique optionnel et les données nécessaires au fonctionnement. Un mode « tout garder sur cet appareil » permet de conserver les réglages uniquement dans le stockage local du navigateur.

alarms

Permet de lancer périodiquement la vérification des délais d’inactivité sans maintenir un minuteur permanent dans une page.

scripting

Permet d’exécuter localement de petits scripts dans une page lorsque cela est nécessaire : par exemple pour détecter une saisie de formulaire, relever l’état d’une vidéo ou vérifier si une réponse IA est encore en cours.

contextMenus

Ajoute les commandes de Tab Suspender au menu contextuel de Chrome pour suspendre, restaurer ou accéder rapidement à certaines actions.

activeTab

Permet un accès temporaire à l’onglet actif lorsque l’utilisateur déclenche certaines actions de l’extension.

favicon

Permet d’utiliser le favicon fourni par Chrome afin qu’un onglet suspendu garde l’identité visuelle du site sans faire de requête vers un service externe de favicons.

system.memory

Utilisée par l’option de suspension d’urgence liée à la mémoire système. Lorsque cette fonction est activée, l’extension peut réagir à une situation de mémoire faible.

Accès aux hôtes

Tab Suspender doit pouvoir intervenir sur les pages ouvertes pour déterminer si une suspension peut avoir lieu sans interrompre une activité importante, puis préparer la restauration. Cet accès est notamment nécessaire aux vérifications de formulaires, de vidéos et de certains états de page.

Code distant

Le code exécutable de l’extension est inclus dans son package. Tab Suspender n’a pas besoin de télécharger du JavaScript ou du WebAssembly depuis un serveur pour fonctionner.

Accès ne signifie pas collecte

Une permission Chrome indique ce que l’extension peut techniquement faire dans le navigateur. Elle ne signifie pas que ces informations sont envoyées à un serveur. Consultez les règles de confidentialité pour connaître précisément les traitements et stockages utilisés.
