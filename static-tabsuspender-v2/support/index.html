Assistance

On va au problème directement.

Les vérifications utiles avant de signaler un bug, puis le contact développeur si le problème persiste.

Un site ne se suspend pas

Vérifiez le délai, la liste blanche, le mode « uniquement ma liste », l’audio, l’état épinglé et les règles propres au domaine. Le diagnostic du popup peut indiquer la cause.

Un site se suspend trop vite

Contrôlez le profil actif et les règles par site. Passez sur 30 min, 2 h ou définissez votre propre délai.

Une vidéo reprend mal

Certains lecteurs réappliquent leur propre timecode ou leur propre vitesse. Testez après un rechargement normal et indiquez le site concerné dans votre signalement.

Les réglages semblent incohérents

Vérifiez si le mode local uniquement est activé, exportez votre configuration si nécessaire, puis redémarrez Chrome avant de refaire le test.

Avant d’envoyer un bug

  • Vérifiez que vous n’avez pas deux extensions de suspension d’onglets actives en même temps.
  • Redémarrez Chrome et reproduisez le problème une fois.
  • Notez le site concerné et ce que vous faisiez au moment du problème.
  • Indiquez la version de Chrome et la version de Tab Suspender.
  • Si possible, donnez les étapes exactes : « ouvrir X → attendre Y → cliquer Z ».

Contact

Confidentialité

Ne joignez pas de mots de passe, de cookies, de clés API ou d’informations sensibles à un signalement. Si votre demande concerne les données traitées par l’extension, consultez d’abord les règles de confidentialité.

Questions fréquentes

Pour les sujets généraux — permissions, vidéos, IA, historique, captures — la FAQ contient les réponses les plus rapides.
